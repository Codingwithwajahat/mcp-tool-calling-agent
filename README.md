# MCP Tool Calling AI Agent 🚀

An AI agent built using **Model Context Protocol (MCP)**, **LangChain**, and **Groq LLM** that enables an LLM to discover and use external tools dynamically.

This project demonstrates how modern AI agents can connect with external capabilities through MCP, allowing the LLM to make decisions, call tools, use resources, and generate responses.

## Features

- 🔹 MCP Server and Client integration
- 🔹 LLM-based tool calling
- 🔹 Dynamic tool discovery
- 🔹 Multiple tool execution
- 🔹 MCP Resources integration
- 🔹 MCP Prompt templates
- 🔹 Async Python workflow
- 🔹 Groq-powered fast inference
